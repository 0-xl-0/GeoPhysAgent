# Integration Package examples

`software-a/` is a complete, installable example for a hypothetical read-only
HTTP API. It demonstrates an external-only natural-language task, MCP stdio Tool
discovery, exact API-origin authorization, environment-based credentials, and
structured Evidence.

The service itself is not included. For a real product, replace the endpoints and
schemas with the vendor's documented read-only API, add contract tests, and change
the package/server IDs. Never put an API key in this directory.

See [`docs/INTEGRATION_PACKAGES.md`](../../docs/INTEGRATION_PACKAGES.md) for the
package format, commands, security model, and current limits.
